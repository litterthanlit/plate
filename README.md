# Plate

Diary for meals out. Letterboxd for local restaurants.

v1 loop: find a place → log a visit → rate + short note → lists.

Portland is the first metro. Data stays in your browser.

## Run

```bash
npm install
npm run dev
```

```bash
npm run typecheck
npm run build
```

## Cut

Booking, delivery, payments, maps-as-product, public review spam, influencer feeds, restaurant claims, AI recommendations.
